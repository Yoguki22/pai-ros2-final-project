# PAI ROS 2 Final Project

## Overview

This repository contains code and configuration files used
for a final project involving ROS 2, CRANE+ V2, and imitation learning.

## Repository Structure

- `airobot_ws/scripts/`: Data conversion, pose processing, and visualization scripts
- `airobot_ws/src/crane_plus/`: CRANE+ V2 ROS 2 package
- `pai_ws/src/physicalai_teleop/`: Teleoperation-related ROS 2 package
- `pai_training/configs/`: Training and data conversion configurations
- `pai_training/scripts/`: Training, inference, and dataset processing scripts
- `pai_training/src/`: Training-related source code

## My Contributions

This project uses existing open-source components and project code.
My work includes project-specific configuration changes and
data processing scripts, as applicable to the final implementation.
